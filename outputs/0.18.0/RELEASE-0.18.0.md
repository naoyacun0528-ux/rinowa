# Lowan 0.18.0

0.17.1 から、**8月20日〜24日ぶんをまとめて版にしたもの**です。
0.17.1 以降の変更が版として存在しない状態が続いていました（端末へ直接入れるだけで、
`outputs/` を更新していなかった）。ここで揃えます。

---

## 暗号化

**封をする単位を「本文の文字列」から「メッセージの中身まるごと」に変えました。**
写真の ID・寸法・**サムネイル**が封筒の外にあると、
「写真の説明文だけ暗号化して写真は平文で送る」ことになります。32px でも写真は写真です。

- `MessageEnvelope` — text / image / video / sticker / call を1つの形式で包む
- 旧形式（素の文字列）も開ける。過去のメッセージを黙って失わないため

**通話の SDP と ICE も封筒に入れました。** これは実害のある穴でした。
WebRTC は相手を **SDP 内の DTLS 指紋**で決めます。平文で置いている間は、
書き換えた者と「完璧に暗号化された通話」を確立できます。ICE には双方の IP も入っていました。

**鍵が消える穴を塞ぎました**（`ToDeviceLedger`）。
受け取った鍵を「取り込む→消す」の2手でやっていたので、その間にプロセスが落ちると
鍵はどこにも存在しなくなります。実際に落ちて、メッセージが2件永久に読めなくなりました。
**初めて見た鍵は消さない**規則にしました。単体テスト6本。

## メディア

- 写真を **XServer の保管庫 + 暗号化**へ移行（Tink AES-GCM-HKDF-STREAMING、鍵は封筒の中）
- **動画**: 端末内で 720p に変換 → 暗号化 → 分割アップロード → **範囲取得でストリーミング再生**
- 動画の**回転**を表示される形で扱う（縦動画が横の枠に入る問題）
- ギャラリーへの保存は **JPEG**（送るのは WebP のまま。渡すファイルはどこでも開ける形式に）
- **オリジナル送信**（設定・既定オフ）と、保存時の「オリジナル / 圧縮版」選択

## バックアップ

Google ドライブの `appDataFolder` に、PIN から導いた鍵で暗号化して保存。
**復元はサーバーに一切書きません** — この端末が読めなかった分を読めるようにするだけです。
単体テスト11本。実機での通し確認は未了。

## 見た目と操作

- 写真ビューア: **横スワイプで会話中の写真を送る**、全体を掴んで下げると閉じる（飛んで消える）
- **予測型戻る**を全画面に。触覚は**3分の1まで無音**、そこから距離に応じて強くなる
- 動画プレイヤーの操作系を作り直し（media3 の既定コントローラを撤去）
- ボタンからキャプションを外し、白い浮いたガラスに

## 直した不具合

- 未読バッジが消えない（サブコレクションへの書き込みでは会話文書が変化しない）
- 通知が**1通ぶん古い**（プッシュは本文より先に着くので、キャッシュから読むと必ず前の1通）
- プッシュが届かない（`push.php` の応答を捨てていた。古いトークンへ送って 200 が返っていた）
- **release ビルドで通話が即クラッシュ** — R8 が `org.webrtc` を改名し、ネイティブ側が
  名前で解決できず `JNI_OnLoad` で abort。**debug でしか試していなかったので出ていなかった**

## 配布

**debug ビルドは配りません。** `android:debuggable` が立っていて、端末を持つ人が
プロセスにデバッガを繋げます。E2EE で守っているはずの本文がそこで読めます。
サーバー上の debug APK 34本と source zip 30本も削除済み。

## iOS の準備

`ios/LowanCore/` — 封筒とバックアップ暗号の Swift 実装。
`research/vectors/formats.json` を **Android と Swift の両方が読む**ので、
形式の食い違いはテストで落ちます。Windows 上で `swift test` が通る状態です。
