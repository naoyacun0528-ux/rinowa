# Lowan 0.17.0 — メッセージが端末間で暗号化されました

**2台の実機で往復を確認しました。** Pixel 10 で送ったメッセージが arrows We2 で復号されて表示されます。

サーバに保存されるのは Megolm の暗号文だけです。**本文のフィールドは存在しません。**

## 通知に本文が出ます。ただし push には載せません

**push は「メッセージが来た」しか運びません。**

本文は**受信した端末が Firestore から取り、自分の鍵で復号してから**通知を組み立てます。
これで通知には本文が出て、`push.php`（自前のサーバ）にも Google にも平文は流れません。
Signal と同じ形です。

**未確認です。** テスト中、push そのものが端末に届きませんでした（通知は1件も出ていません）。
暗号化とは別の問題で、次に見ます。

## 出荷していたら E2EE が無意味だった穴を2つ塞ぎました

**1. 会話一覧のプレビューが平文でした。**
`lastMessage.preview` は**サーバが読めるドキュメント**です。暗号化しても
**各会話の最新1通が丸見え**になっていました。`🔒 メッセージ` に置き換えました。

**2. プッシュ通知が本文を運んでいました。**
自前のサーバと Google の両方に平文が渡ります。しかも**アプリを閉じている間に届く
メッセージ全部**がその経路です。

## 動かなかった原因は3つ。どれも例外も警告も出しませんでした

**1. 鍵の宛先が0件だった。**
FFI は `{"messages": {...}}` の**包み無しで**宛先マップを渡します。包みを探して見つからず、
**誰にも配らずに正常終了**していました。`count=0` を印字するまで見えませんでした。

**2. Megolm セッションが「配布済み」で固まっていた。**
相手が鍵を公開する前に作ったセッションが残ると、`shareRoomKey` が**要求0件**を返し続けます。
本物の Matrix ではサーバが端末一覧の変更を通知して無効化しますが、**Lowan にサーバはありません。**
検出したら捨てて作り直します。

**3. 受信箱を一括削除していた。**
取り込めなかった鍵まで消えます。**そのメッセージは、以後どの端末でも永久に読めません。**
「読んでから消す」と書いていましたが、正しい規則は**「取り込めたものだけ消す」**でした。

### そして、検査そのものが間違っていました

`runCatching { }.onSuccess { }` を「失敗を処理済み」と判定していて、
**実際に握り潰されていた to-device の書き込みを見逃していました。**
`.onSuccess` は失敗を見ません。

> **誤検出する検査より、見逃す検査のほうが悪い。**
> 緑のビルドが証拠として扱われるからです。

## 送信側が配達を確認できるようになりました

規則を1行足して、**差出人は自分が投函したものだけ読み返せる**ようにしました。

これは情報を渡していません（本文を作ったのは差出人です）。埋めたのは**検証の穴**で、
「書き込みは成功、受信箱は空」という状態が**どちら側の問題か判定できなかった**ためです。
実際、この読み返しが `present=true` を返した時点で切り分けが終わりました。

## 古いメッセージは 🔒 のままです

配達バグを直す前に送ったものは、**鍵が本当にどこにも届いていません。**
開かないのが正しい状態です。空欄にはせず「まだ開けません」と出します。
