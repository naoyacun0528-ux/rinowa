# この版の source.zip は、中身が tar です

2026-09-05 に気づいた。`rinowa-0.20.3-source.zip` は拡張子が `.zip` だが、
**実体は tar 書庫**（257バイト目に `ustar` の印がある）。Windows の
エクスプローラーでは開けない。

原因は、この2版だけ `tools/release.ps1` を通さず手で作ったこと。
「入っているファイルは合っているか」しか確かめず、**開けるかどうかを
確かめていなかった。** 中身そのものは無事で、tar として展開すれば全部出てくる。

## どうしたか

**元は1バイトも触っていない。** 隣に `repacked/` を作って、同じ中身を
本物の zip で置いた。

```
rinowa-0.20.3-source.zip           元のまま（中身は tar）
repacked/rinowa-0.20.3-source.zip  同じ中身。開ける
```

元を消さなかったのは、これが配った成果物だから。**差し替えると、
受け取った人が持っているものと食い違う。**

## 展開のしかた（元のほうを開きたい場合）

```
tar -xf rinowa-0.20.3-source.zip
```

0.20.5 以降は `tools/release.ps1` が作るので、本物の zip になっている。
