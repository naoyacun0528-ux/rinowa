# Lowan 0.13.0 — Echo から改名しました

**アプリ名が Echo から Lowan（ろわん）になりました。**

## 上書き更新できます

**`applicationId` は `blog.nextlab.echo` のまま**です。変えたのは表示名と画面の文言だけなので:

- **アンインストール不要。そのまま上書き更新されます**
- 会話もアカウントもそのまま（Firestore 側は何も触っていません）
- 配布 URL も変わりません

利用者に見えない文字列を変える理由がありません。X が今も `com.twitter.android` なのと同じです。

## なぜ Echo をやめたか

**日本語で「エコー」は心エコー・エコー検査の言葉です。** 「エコーしよ」と言ったとき、
音の反響ではなく超音波検査が先に立ちます。**名前を動詞にしたときに別の意味が先に来る**のは、
毎日使うアプリとしては失格でした。

同じ理由で Relay も落ちています（リレー競走・中継）。

## なぜ Lowan か

順番どおりに書きます。**音が先で、意味は後から見つかりました。**

1. **ライン・ピングと同じ「3モーラ・ン止め」**を条件にした
2. ロ◯ンの空きを探すと、**ロワン以外はほぼ全部埋まっていた** — ローラン、ロマン、ロナン、ロダン、ロビン、ロザン、ロガン、ロハン
3. **和語はラ行で始まりません。** だから語頭がラ行だと、その瞬間に固有名詞だと分かり、助詞と混ざらない。LINE が言いやすい理由と同じ
4. `Rowan` は Play に同名アプリと Rowan 大学があった。**日本語ではLとRを区別しないので、`Lowan` にすると音は同じまま文字列だけ別**になる
5. **調べたら、Lowan はオーストラリアのツカツクリのアボリジニ名で、語源はその鳥が危険を感じたときに発する鳴き声だった**

**5番は後から知ったことです。** 由来から選んだのではありません。

## 変わったもの

- ランチャー名、サインイン画面、チャット一覧の見出し、着信画面
- ステッカーの内蔵パック名、アカウント削除の説明、Lowan Direct
- **写真の保存先が `Pictures/Lowan` に**なりました。**改名前に保存した写真は `Pictures/Echo` に残ります。** 勝手に移動させません

## 変えていないもの

- パッケージ名 `blog.nextlab.echo`
- ソースコードの識別子（`EchoTheme` など）。全部触ると差分が読めなくなるので、別の判断として分けます
- 配布ファイル名と URL。**変えるとテスターに渡したリンクが死にます**
- 通信形式 **Rinowa** の名前。こちらは別の層の名前です
