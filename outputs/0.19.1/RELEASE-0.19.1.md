# Lowan 0.19.1

通話まわり6件。すべて実機で確認済みです。

## 1. 発信側が切っても相手が鳴り続けた

鳴らしているのは push で起きた `IncomingCallService` で、**通話が終わったことを知る経路が
ありませんでした**。止まるのは、出た・拒否した・30秒経った、のどれかだけ。掛けた側が
切っても、相手の端末は誰も居ない電話を鳴らし続けます。

コードにも「発信側が切ったあとも鳴っている端末は人を無駄に走らせる」と書いてあり、
その時点で時間切れしか手当てがありませんでした。

通話ドキュメント1件を見張って、`ringing` でなくなった時点で鳴りやむようにしました。
30秒の時間切れは保険として残します（相手が圏外に落ちて「終わった」が書かれないことは
あるため）。

## 2. 通話の記録が灰色の丸だった

メッセージは自分＝オレンジ・右、相手＝暗い色・左なのに、通話だけ左右どちらも同じ灰色
でした。自分が掛けたのか掛かってきたのかが、文面を読むまで分かりません。

吹き出しと同じ色・同じ左右に揃えました。不在着信の赤はその上に残します。

## 3. 通話の記録が相手の端末に出なかった

`recordCall` が `members` を渡していませんでした。既定は「送信者だけ」なので、**通話の
記録は発信した端末にしか復号できない形で暗号化されていました**。書き込みは成功して
いるので、どこにも失敗が出ません。相手の画面には最初から存在しないか、鍵の無い行が
1つ増えるだけでした。

会話の参加者を渡すようにしました。

### 直す前に作られた記録について

すでに書かれてしまったものは**開けないままです**。鍵が発信者の端末にしか無く、あとから
配り直す経路もありません。相手の画面には「まだ開けません」として残ります。今日の検証で
6件ほど作りました。消すなら発信した側から取り消せます。

## 4. 発信するとキーボードが残った

入力中に通話ボタンを押すと、通話画面の下でキーボードが出たままでした。閉じて、入力欄の
フォーカスも外します（隠すだけだと入力欄が待っていて戻ってきます）。書きかけの文字は
残ります。

## 5. 押した瞬間に発信していた

相手の端末を鳴らすのは取り消せないので、一度訊きます。「音声通話を発信しますか /
〈相手〉の端末が鳴ります。」

## 6. ビデオ通話の操作が消せなかった

画面をタップすると操作が出ますが、出ている状態で押しても同じ「出す」でした。押した
手応えだけあって何も起きないのと同じです。出ているときに押したら消えるようにしました。

## 確認したこと

- コンパイル：エラー0・警告0、単体テスト70件すべて通過
- 実機（Pixel 10 → arrows We2、どちらも release の 0.19.1）
  - 入力中に通話ボタン → キーボードが消え、確認が出る
  - 通話の記録がオレンジ・右（自分）／暗い色・左（相手）で並ぶ
  - 鳴っている最中に発信側で切る → **相手の着信が消える**（通知0件）
  - その通話の記録が相手にも届き、「不在着信」として出る
  - ビデオ通話を接続 → タップで操作が出る → もう一度タップで消える
  - 通話時間 0:58 と 1:42 の記録が両方の端末に出る

(6) は arrows We2 で確認しました。Pixel 側は検証中に端末の利用時間制限に達して Lowan が
使えなくなったためです。端末の設定なので触っていません。
