# Lowan 0.18.2

動画が、**列の中で**再生されるようになりました。

0.18.1 では再生プレイヤーが別画面で、写真ビューアの上に開いていました。つまり再生を押した
瞬間に列から出ていたので、**横スワイプが効かず、下へのドラッグでも戻れませんでした**。
会話の中の動画は、まわりの写真と同じ列の1枚です。ここでも1枚のままにしました。

- 再生は**そのページの上**で起きる。スワイプはそのまま次の写真・動画へ進む
- 再生中でも下へドラッグすればチャットに戻る
- ページを離れると再生は止まる（画面の外で音だけ鳴り続けない）
- チャットの動画をタップすると、その動画の位置で列が開く（写真と同じ入り口）
- 閉じる・保存はビューア側の同じボタンのまま

## 戻るジェスチャーの触覚が二重だった

システムは戻るジェスチャーが確定した瞬間に自分で触覚を鳴らします。そこにアプリの
「戻るボタンを押したときの触覚」を重ねていたので、**2回叩かれていました**。ボタンには
必要（ボタンの裏には何もない）ですが、ジェスチャーには要りません。アプリ側の最後の1回を
やめました。引いている最中の段階的な触覚は今までどおりです。

## バックアップ画面が通知バーに潜っていた

画面の一番上から描き始めていて、見出しが時計と重なっていました。ステータスバーと
ジェスチャーバーを避けるようにし、見出しの下に間隔を入れました。
