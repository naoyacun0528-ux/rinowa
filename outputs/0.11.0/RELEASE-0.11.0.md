## 音声通話

**会話画面の右上の受話器を押すと発信します。**

- 相手の画面に**着信が出ます**（アプリが開いていれば）
- **鳴る前に手に来ます。** 伏せて置いた端末を、音を聞いていない人が取れるように
- 応答と拒否は**離して置いています**。寝起きに間違えて出るのが最悪なので
- `呼び出し中 → 接続中 → 通話中` を**出し分けます**。この数秒が黙っていると、
  人は切って掛け直し、それが失敗を確実にします
- ミュート・スピーカー・終了

### 今日確実に動くのは「同じ Wi-Fi」です

**同一 Wi-Fi なら、サーバーを一切通しません。** 2台がお互いのローカルアドレスを
見つけて直接つながります。STUN も TURN も出番がありません。

**別の回線同士だと、繋がる場合と繋がらない場合があります。** これが TURN の話です。

### TURN について

**「たまに繋がらない通話」は「繋がらない通話」です。** 同意します。**必ず用意します。**

ただし TURN は「要るか」ではなく「**どれにするか**」の問題なので、
**Cloudflare の TURN で始めます**（無料枠が大きく、運用するサーバーが増えない）。
費用か依存が問題になったら東京の VPS へ移します。**切り替えは ICE サーバー一覧の差し替えだけ**です。

**まだ入れていません。** 今日の版は STUN のみなので、
**まず同じ Wi-Fi で試してください。** 別回線で失敗した回数が、TURN 投入の根拠になります。

### 通話で隠さないこと

- **通話の事実（誰といつ何分）は Firestore に残り、我々に見えます。**
  本文が読めないのとは別の話なので、同じ強さで書いておきます
- **相手に IP が渡ります。** 直接繋ぐとはそういうことです。
  だから通話は**友達追加済みの相手だけ**にします
- 暗号は **DTLS-SRTP**（WebRTC 内蔵・切れない）。**自作していません**

## 写真をタップで全画面

- **ピンチで拡大、下にドラッグで閉じる**
- 下に **削除・共有・保存**
- 削除は**自分が送った写真だけ**。他人の写真を相手の端末から消す機能は作りません
- 保存は MediaStore 経由なので**ストレージ権限を要求しません**
- 共有は1枚だけを `content://` で渡します。**保持している写真全部が見えたりはしません**

## 衛星通信（Starlink Direct）— 設計と検出を入れました

`docs/SATELLITE.md`

### いちばん重要なこと

**専用の SDK は要りません。** Direct to Cell は衛星が LTE 基地局として振る舞うので、
アプリから見ればただの携帯回線です。

**やるべきことは「衛星だと気づいて、余計なことを全部やめる」ことです。**

### 「遅い4G」ではありません

衛星の footprint 全体で数 Mbps を分け合うので、**1端末あたりキロビット単位**です。
これを普通の回線として扱うアプリは、**遅くなるのではなく何も届きません**。

### 気づく方法

Android 15 の `NET_CAPABILITY_NOT_BANDWIDTH_CONSTRAINED`。
**「制約されていない」という肯定形の能力なので、無いことが制約を意味します。**
実装済み（`LinkClass.kt`）。

**Android 15 未満は「判定不能」として通常扱いにします。**
憶測で細いと決めつけて、普通に動いている回線を勝手に制限するほうが害が大きいので。

### 衛星のときにやめること

写真の送受信・スタンプ取得・プロフィール画像・**既読**・在席表示。本文は500字まで。

**既読を止めるのが効きます。** 1通読むたびに1書き込みで、本文と同じ費用を
「見たよ」に使うことになるので。**ただし説明が要ります** —
黙って既読が付かないと、それは「無視された」と読まれます。

### Firestore は衛星で動かないと考えるべきです

Firestore は gRPC の長時間接続を張ります。**接続の確立自体が終わりません。**
遅くなるのではなく、何も起きない。

なので**別経路が要ります**: EWF + 辞書圧縮 → **HTTPS POST 1回** → 自前サーバー → Firestore。

### そしてここが EWF の本当の使い所でした

| 形式 | 1通 |
|---|---|
| JSON | 267 B |
| EWF | 98 B |
| **EWF + 辞書** | **43 B** |

**同じ帯域で6倍の通数**が入ります。仕様を凍結しておいたのは、この経路のためです。

### 約束しないこと

**衛星で通話はできません。帯域が3桁足りません。** 写真も送れません。
「衛星対応」と書いて通話ができると誤解されるのが最悪なので、
画面には**できることだけ**を出します。

**衛星での実測は一つもありません。** 対応端末も契約もないので、
**実機で通るまで「対応した」とは言いません。**
