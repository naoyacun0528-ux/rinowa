# Lowan 0.19.2

## 戻るときのアニメーションが右へ動いていた

設定の子画面（バックアップ、プライバシー、プロフィールなど）から設定へ戻ると、戻って
いるのに**進む向きの動き**になっていました。左から出てくるはずの画面が右から入ってきます。

向きの判定が「行き先が一覧でなければ進む」だったためです。子画面から親へ戻るときも
行き先は一覧ではないので、進む扱いになっていました。一覧まで戻るときだけ正しく
動いていたことになります。

一覧から何階層めかで判定するようにしました。深いほうへ動くなら進む、浅いほうへ動く
なら戻る。階層は既存の `parent()` から数えます。親子関係を2か所に書くと、片方だけ
直した日に向きだけが静かに狂うためです。

実機で、バックアップ → 戻る の途中を撮って、アカウントの画面が左から入ることを
確認しました。

## 直していないもの：Drive のバックアップが 403

```
drive upload 403: Google Drive API has not been used in
project 321506749950 before or it is disabled.
```

これはアプリ側の不具合ではなく、**Google Cloud プロジェクトで Drive API が有効に
なっていない**というだけです。コードは正しく呼んでいて、断っているのは Google です。

有効化はコンソールでの操作なので、こちらでは行っていません（gcloud も入っていません）。

<https://console.developers.google.com/apis/api/drive.googleapis.com/overview?project=321506749950>

有効化してから数分待つと通ります。それでも 403 が続く場合は、OAuth 同意画面に
`https://www.googleapis.com/auth/drive.appdata` のスコープが登録されているかが次の
確認点です。

このスコープは**アプリ専用フォルダだけ**で、利用者の他のファイルは見えません。
バックアップの中身は端末で暗号化してから置くので、Google からも読めません。
