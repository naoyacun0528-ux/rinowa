# Lowan 0.18.9.2

0.18.9.1 の切り替わりが3拍になっていたのを直しました。

## 終わったらそのまま戻る

「再生が終わる → 操作列が出る → 少し待つ → ポスターに戻る」と見えていました。原因は2つ
重なっていて、どちらもこちらの作りです。

1. **終端で操作列を自動で出していた**。プレイヤーが終端の1枚を出したまま留まっていた頃の
   処理で、「先頭へ戻る手段が無いまま静止画だけが残る」のを避けるためのものでした。
   いまは終わったらポスターに戻るので要りません。出してすぐ消すぶん、プレイヤーが
   立ち上がり直したように見えていました。
2. **0.6 秒の間を置いていた**。最後の1枚を見せるつもりで入れましたが、ポスターは
   その1枚目なので、待つ意味がありませんでした。

両方外して、終端に着いた時点でそのまま戻します。

## 確認したこと

- コンパイル：エラー0・警告0
- 実機（Pixel 10、release）で最後まで再生 → 引っかかりなくポスターへ戻り、削除・共有・
  保存の3つが出た

0.18.9 と 0.18.9.1 の内容はそれぞれの `RELEASE-*.md` を参照。
