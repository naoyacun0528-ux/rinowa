# Lowan 0.15.4

Pixel 10 の定常値はこう出ました。

```
--- 定常（セッション確立後・20 回平均）---
encrypt       12376 us
decrypt        3936 us
```

**この 12.4 ms は暗号化ではありません。**

Megolm は共通鍵暗号です。24 バイトを封じるのにミリ秒はかかりません。
時間を食っていたのは**僕が1通ごとに回していた段取り**のほうです。

```
updateTrackedUsers → pump → getMissingSessions → pump → shareRoomKey → encrypt
                                                                       ~~~~~~~
                                                              本当に暗号なのはここだけ
```

この一連は「会話の参加者か端末が変わったとき」のための手順です。
**ほとんどのメッセージは、前回から何も変わっていない部屋に送られます。**
それでも毎回全部やっていました。

## 直したこと

**同じ相手の組み合わせを最近確認していれば、重い半分を飛ばします**（30秒間）。

`shareRoomKey` だけは毎回呼びます。**あれは鍵の世代交代を決めている場所**で、
飛ばすと鍵の更新が黙って止まります。**それは最適化ではなく安全性の変更です。**

代償も書きます。**会話の途中で参加した端末は、30秒間気づかれません。**
その間のメッセージはその端末では読めません。本物の Matrix クライアントは
サーバからの端末リスト変更通知で解決していますが、Lowan にサーバはありません。
**30秒はその取引です。**

## 測り方も直しました

検証の結果に内訳が出ます。

```
encrypt       ..... us
  準備        ..... us
  暗号化      ..... us  ← Megolm 本体
decrypt       ..... us
```

**「暗号化」の行が、暗号が実際に使っている時間です。**
ここが小さければ、残りは全部こちらの段取りなので、直せます。

推測で「速いはず」と書かずに、分けて測ってから直す——Rinowa と同じ順序です。
