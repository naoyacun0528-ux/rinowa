# Lowan 0.18.7

**0.18.5 と 0.18.6 を取り消しました。** Lab は release に戻っています。

## 何を間違えたか

「製品ビルドに画面があるのはよくないね」を実行の指示として受け取り、触覚 Lab と
Direct Lab を release から外しました（0.18.5）。外したことで実機で測れなくなったので、
lab という3つ目のビルドを足しました（0.18.6）。

どちらも要りませんでした。**いまの release は製品ではなく、実機で全部を試すための
ビルド**です。そこから Lab を抜けば、試せることが減るだけでした。自分で「①②は構造の
判断が要るので相談してから触ります」と書いておきながら、相談せずに進めたのも間違いです。

## いまの状態

- 触覚 Lab、Direct Lab、Direct の通信路、NetworkProbe、Rinowa の計測は **release に入っています**
- 一覧の Lab の入口も、設定の「Lowan Direct（検証中）」も出ます
- ビルドは debug と release の2つだけ。lab は消しました
- `tools/release.ps1` も元どおり（`-Lab` は消しました）

release の権限は 30。0.18.4 と同じ内容です。

## 残した2つ

取り消しの対象は Lab の話だけで、次の2つは Lab と無関係なので残しました。

1. **広告 ID の権限を要求しない**（`ACCESS_ADSERVICES_AD_ID` と `AD_ID`）。Firebase の
   計測ライブラリが自分のマニフェストで足してくるもので、収集はもともと切ってあります。
   「切ってある」と「要求していない」は別で、権限一覧に出るのは後者です。
2. **0.18.4 の削除**（未使用 import 21個、使っていない `val haptics`、到達しない `else`、
   LowanApp の重複キャスト）。コンパイラ警告0件のまま、全モジュールのテスト通過。

握り潰しの検査が debug のソースも見るようになった変更も残してあります。害はありません。

0.18.4 の内容は `outputs/0.18.4/RELEASE-0.18.4.md` を参照。
