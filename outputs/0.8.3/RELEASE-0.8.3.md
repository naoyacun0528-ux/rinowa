# Echo 0.8.3

## 固定ダウンロードURL

**毎回変わらない URL になりました。**

```
https://echo.nextlab.blog/dly5sfc4x1/download.php?f=echo-latest-debug.apk
```

これをブックマークしておけば、以後は常に最新版が落ちてきます。バージョン番号入りのファイルも同じ場所に残るので、古い版と比べたいときは名前を指定すれば取れます。

キャッシュを無効にしてあります。`latest` は**名前が同じまま中身が変わる**ので、キャッシュが効くと古いビルドが最新の名前で返ってきます。固定URLにすると必ず出る事故なので、`no-store` を明示しました。

リリースノートも `?f=RELEASE-latest.md` で同じように取れます。

## 取り消しの表示に名前

相手が取り消した場合は **「○○がメッセージの送信を取り消しました」**、自分のときは **「メッセージの送信を取り消しました」** になります。

グループで「メッセージが取り消されました」とだけ出ると、**5人のうち誰なのか分からない**まま残ります。疑問を生む通知は、通知が無いよりも悪いので。
