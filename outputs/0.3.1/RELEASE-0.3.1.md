# Echo 0.3.1

2026-08-15 / Prototype 0 / Android only

0.3.0 のガラスを入力まわりへ広げました。

---

## 変更点

### メッセージ入力バーがガラスになった

テキスト欄が角丸のガラス面になり、`+` / スタンプ / 送信ボタンと同じ素材で揃いました。

**ただし押しても膨らみません。** テキスト欄は「押すもの」ではなく「フォーカスするもの」で、
膨らませると意味が変わってしまうためです。
そのため見た目だけを取り出した `Modifier.glassFace()` を用意し、
押して反応する `GlassSurface` と作り分けています。

### 送信ボタンが送信時に弾む

- **押している間**: 少し膨らむ（1.09倍）
- **送信した瞬間**: 一度大きく膨らんで（1.20倍、70ms）、ばねで戻る

メッセージが飛んでいく動きと、ボタンが手を離す動きを同じ一回の運動にしています。
触覚の `send` と同じ瞬間に始まります。

---

## 素材の使い分け

| | 押すと膨らむ | 使う場面 |
|---|---|---|
| `GlassSurface` | **する** | 会話カード、`+`、スタンプボタン |
| `Modifier.glassFace()` | しない | 入力欄、今後のパネル類 |

「押せるものだけが押し返す」という区別を、見た目ではなく**挙動**で表しています。
