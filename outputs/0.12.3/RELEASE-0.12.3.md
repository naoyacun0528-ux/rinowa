# Echo 0.12.3 — ビデオ通話の3つのバグ

```
https://echo.nextlab.blog/dly5sfc4x1/download.php?f=echo-latest-debug.apk
```

---

## 1. 終了を押すと固まる（Echo が応答していません）

**いちばん深刻なやつでした。**

通話の後片付け（カメラを止める・接続を破棄する）を、**ボタンを押したスレッド＝メインスレッド**でやっていました。

- `stopCapture()` は**カメラのスレッドが実際に止まるまで待ちます**
- `dispose()` も同じくネイティブ側の完了を待ちます
- カメラが開いていると、これが**秒単位**になります

Android はメインスレッドがその長さ止まると「応答していません」を出します。
**音声通話でも遅かったはずですが、カメラの分だけビデオで顕在化しました。**

**直し方**: 参照を先に外して、遅い後片付けは専用スレッドへ。
**画面はタップしたフレームで閉じ**、カメラは自分のペースで手を離します。

---

## 2. 画面に黒が挿入される

**これは映像の乱れではなく、描画の重なりの問題でした。**

`SurfaceView` は「ウィンドウの後ろに映像を置き、ビューが穴を開けて見せる」仕組みです。
**2つ重なると、上のビューが下の映像に穴を開けて、その部分が真っ黒になります。**

自分の小窓と相手の全画面が、まさにその配置でした。

**直し方**: 小窓のほうを手前の層に置きます（`setZOrderMediaOverlay`）。
穴が開く先が「相手の映像」から「ウィンドウ」に変わります。

映像の受信やコーデックの問題ではなかったので、**画質側は何も触っていません。**

---

## 3. ビデオ通話で相手に着信が飛ばない

権限のダイアログの結果を**取り違えていました**。

マイクとカメラをまとめて要求したとき、**すでに許可済みの権限は結果に含まれないことがあります**。
それを「拒否された」と読んで、発信そのものを止めていました。
**通話も鳴らず、エラーも出ない**——いちばん分かりにくい形です。

**直し方**: 結果の一覧を読むのをやめて、**システムに直接聞きます**。

---

## 画面の作り直し

**自分の映像を左上へ。** 右上には時計と電池があり、その下に置くと隅に物が積み上がって見えます。

**角丸を大きく**（20dp）。

**自分の小窓をタップすると入れ替わります。** 大きいほうが自分になります。
自分の写り方を確認したいときや、カメラに何かを見せたいときは、**大きい枠が欲しいのは自分の側**なので。

**カメラの前後切替を、小窓の角に。** 「前」「後」と出ます。
**変える対象のすぐ隣**に置きました。下のボタン列から独立させています。

## 試してほしいこと

1. **ビデオ通話で相手が鳴るか**
2. **黒い帯が出ないか**
3. **終了を押して固まらないか**
4. 小窓のタップ入れ替え、前後切替

音声通話の切断が「すぐ切れたか / 6秒待ったか」も、まだ知りたいところです。
