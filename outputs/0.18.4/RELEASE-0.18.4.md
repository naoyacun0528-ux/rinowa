## チャットを開いたら通知が消える

開いた時点と、開いたまま次が届いた時点で、その会話の通知を消します。読んでいる人に
「未読があります」と言い続けないため。実機で確認: We2 から送る → Pixel に通知が出る
（本文つき）→ Pixel でその会話を開く → 通知が消える。
