# Echo 0.4.1

2026-08-15 / Prototype 0 / Android only

すりガラスの切り替わりをアニメーション化し、リアクションピッカーもすりガラスにしました。

---

## 変更点

### ぼけがパッと切り替わらなくなった

スクロールを止めた瞬間にぼけが出るのが不自然、という指摘への対応です。

**クロスフェードではなく、ぼかし半径そのものを動かしています。**

これは見た目のためだけの選択ではありません。半径 0 のとき、取り込んだ背景は
**素通しの内容とピクセル単位で同一**になります。つまり継ぎ目が原理的に存在しません。
ぼけた複製を重ねてフェードすると、一瞬「二重に見える」状態を必ず経由します。

速度は非対称にしました。

| | 時間 |
|---|---|
| 動き出す（ぼけが消える） | 130 ms |
| 止まる（ぼけが戻る） | 280 ms |

指を動かした瞬間は素早く外れ、落ち着くときはゆっくり合う。カメラのピント送りと同じ考えです。

ぼけが**消えきるまで背景の取り込みを続ける**ので、遷移中に古い映像が固まることもありません。

### リアクションピッカーが常にすりガラスになった

ピッカーは静止中にしか出ないので、常時ぼかしても走行中のフレームを一切奪いません。
暗転したスレッドの上に浮かぶので、ぼかす材料も十分にあります。

ぼかしは 22dp（バーの 18dp より強め）。浮いている距離感を出すためです。

## 性能

| 指標 | 0.3.2 | 0.4.0 | **0.4.1** |
|---|---|---|---|
| Janky frames | 0.74% | 3.29% | 4.70% |
| 50th percentile | 6 ms | 7 ms | 8 ms |
| 90th percentile | 10 ms | 12 ms | 15 ms |

数字は少し戻っています。ただし**この測定は最悪条件**です。
8秒間に**10回スクロールを開始・停止**しており、そのたびにピント送りが走ります。

実際の利用では、止めたり動かしたりを1秒に1回以上繰り返すことはまずありません。
**数字より指の感覚を優先して判断してください。** 重く感じるなら戻します。
