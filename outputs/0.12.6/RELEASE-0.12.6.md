# Echo 0.12.6

## PiP で切っても小窓が残った件

通話は終わっていました。相手も切れていました。**小窓を閉じる処理が無かっただけです。**

**Android にはピクチャインピクチャを抜ける API がありません。** 出る方法は2つだけで、
「利用者が窓を広げる」か「Activity が終わる」かです。何も呼んでいなかったので、
通話の無いアプリを映した小窓がそのまま残っていました。

通話が終わった時点で小窓に居るなら Activity を終了するようにしました。
これは回避策ではなく、正しい振る舞いだと考えています——小窓から通話を切る人は
別のことを見ている最中で、Echo は消えてその場に戻すのが正解です。

**全画面から終了したときは閉じません。** 条件は「PiP に居ること」だけに絞ってあります。

## アイコンを1つにしました

**ランチャーは同心円4本、通知バーは開いた弧3本と、1つのアプリに2つのマークがありました。**
通知シェイドに出るものとホーム画面に出るものが似ていない、というのは、
いちばん一瞬で見分けたい場所で見分けられないということです。

ランチャー側を通知と同じ弧3本に描き直しました。座標は通知用の 24dp の絵を
X = 54 + (x - 10.6) × 2.8、Y = 54 + (y - 12) × 2.8 で置いたもので、
いちばん外の線もアダプティブアイコンの安全域（66dp）の内側に収まります。

**円はランチャーが被せる形であって、マーク自体が円である必要はありません。**
角丸四角のランチャーでも、マークは同じ形のまま出ます。

テーマ付きアイコン用に、濃淡を付けない版を別に用意しました。あちらは
システムが単色で塗り直すので、濃淡がそのまま3種類の灰色になってしまいます。

### 1つだけ残っている不整合

`mipmap-*/ic_launcher.png` は **Android 7（API 24-25）用の旧いラスタ画像で、
古いマークのままです。** ベクタから PNG を焼き直す手段が今の環境に無いためです。
手元の3機種は API 36/37 なので実害はありませんが、直っていないものを
直ったことにはしません。
