## 1. 別の回線同士でつながるようにしました

**TURN（中継サーバー）を入れました。**

これまでは同じ Wi-Fi でしか確実に繋がりませんでした。両側が別の回線にいると、
お互いの住所を教え合っても届かない——それが TURN が要る理由です。

### 置き場所をアプリに埋めていません

**`https://echo.nextlab.blog/ice.php` から取ってきます。**

理由が2つあります。

**TURN のパスワードは短命でなければいけません。** APK に固定パスワードを埋めると
数分で取り出され、そこから先は**他人の帯域**になります。

**提供元は必ず変わります。** アプリに埋めていたら、変えるたびにアプリを出し直して、
その間は半分の端末が古い設定で動くことになります。サーバーから配れば **PHP を1行直すだけ**で、
全端末が次の通話から新しい設定を使います。

### 今入れているのは一時的なものです

**Open Relay Project という公開の無料 TURN** を使っています。**差し替える前提です。**

- 通話の中身は **DTLS-SRTP** で端末間で暗号化されているので、**中継は復号できません**。
  中継が見るのは両端の IP と通話時間です
- ただし**無料の公開中継は best-effort** で、混んでいれば繋がりません。
  「他人の無料枠が空いていれば通話できる」は、メッセンジャーとして成立しません
- **固定パスワード**です。公開されているので誰でも使えます

**次に Cloudflare か東京の VPS に移します。** そのときアプリの更新は要りません。

### 中継が無いときは画面に出します

もし取得に失敗して STUN だけになったら、通話画面に
「**中継サーバー未設定 — 同じ Wi-Fi 以外では繋がらないことがあります**」と出ます。
繋がらないのを黙って見せられるより、理由が分かるほうがましなので。

## 2. 着信を「電話」にしました

前の版はアプリを開いているときしか気づけませんでした。直しました。

### 鳴り続けます

**通知チャンネルの音は1回しか鳴りません。** メッセージには正しくても、電話には間違いです。
1回だけ震えて黙る電話は、鳴っていません。

なので**前面サービス**が持ちます。

- **端末の着信音をループ再生**（アプリ固有の音ではなく、**あなたがいつも使っている着信音**）
- **バイブは繰り返し**（0.8秒振動 → 0.9秒休み → 繰り返し）
- **応答（緑）／拒否（赤）** — Android の `CallStyle` なので、
  標準の電話アプリや LINE と**同じ見た目・同じ位置**です
- **ロック画面の上に全画面で出ます**

### 止まります

応答・拒否・**30秒**のいずれか。

**発信側が諦めた後も鳴り続ける電話は、鳴らないより悪いです。**走らせることになるので。
プッシュ自体にも 30 秒の期限を付けました——30秒後に鳴り出す着信は、遅い通知ではなく**間違った通知**です。

### マナーモードは尊重します

- **サイレント**: 音も振動もしません
- **バイブのみ**: 振動だけ
- どちらもユーザーの判断であって、事故ではないので、上書きしません

### 応答してもロックは解除しません

会話の中身は非公開なので、**応答＝ロック解除の抜け道**にはしません。
ロック中に応答すると、まず解除を求めます。

## 3. 実装上の注記（詰まったときの手がかり）

**前面サービスの型は `mediaPlayback` です。** 名前としては `phoneCall` のほうが合いますが、
Android 14 以降は Telecom に登録済みの通話アプリであることが条件で、Echo はまだそうではありません。
**通らない型を名乗るとサービスが起動せず、結果は「鳴らない」です。**
それでも拒否された場合に備えて、通知だけは出す経路を残してあります。

**全画面通知の権限は実行時に確認します。** Android 14 以降は付与されないことがあります。
その場合はヘッドアップ通知（画面上部のバナー）に落ちますが、
**応答・拒否のボタンは同じように出ます**。

## 試し方

1. **両方の端末を更新**
2. 片方でアプリを**完全に閉じる**（または画面を消す）
3. もう片方で会話を開き、**右上の受話器**
4. 閉じている側が**鳴り続け、応答/拒否が出る**はず

**別の回線でも試してください。**繋がらなかった場合、
通話画面に出ている文言をそのまま教えてもらえれば原因が分かります。
