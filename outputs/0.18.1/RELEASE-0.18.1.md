# Lowan 0.18.1

写真ビューアの横スワイプに、**動画も入れました**。

0.18.0 では写真だけを集めていたので、スワイプすると**動画が送られていなかったかのように
飛ばされていました**。穴のあいた列は、その会話の列ではありません。

- 会話の写真と動画を古い順に1つの列として送れる
- 動画のページは**メッセージの中に入っている1枚目**をすぐ出す（本体は再生を押すまで取りに行かない）
- 動画のページでは 保存 が出る（共有は出さない — 共有シートは端末にまだ無いファイルを待てないため）
- 削除は**1枚ごと**に自分のものか判定する。会話は 二人の写真が混ざった列なので

0.18.0 の内容は `outputs/0.18.0/RELEASE-0.18.0.md` を参照。
