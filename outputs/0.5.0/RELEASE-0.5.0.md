# Echo 0.5.0 — Prototype 1 バックエンド

ROADMAP の Prototype 1、項目 **2〜9 を実装**。1（認証）は 0.4.x で完了済み。

---

## 入ったもの

### 2. Account データモデル

| Firestore | 中身 |
|---|---|
| `users/{uid}` | 表示名・アイコンURL・招待コード |
| `users/{uid}/settings/app` | 触覚設定・計測オプトアウト（端末をまたぐ） |
| `users/{uid}/stickerLibrary/owned` | 所有・お気に入り・履歴。**参照だけで画像は入れない** |
| `inviteCodes/{code}` | コード → uid |

**メールアドレスでの検索は用意しない。** 用意すると「このアドレスの人は Echo を使っているか」に
誰でも答えられるサービスになってしまう。本人が渡したコードでしか見つからない形にした。
`I` `O` `0` `1` を使わない8文字なので、口頭で伝えても崩れない。

### 3. 実メッセージング

- Direct 会話の作成・送受信・既読
- リアクションは1人1つ。Firestore 上も uid をキーにしたマップで、**自分のキーしか触れない**
- 返信、日付区切り、送信中表示
- オフライン永続化を有効化。電車で開いても、キャッシュから即座に出る
- 送信は Firestore のローカル書き込みが先に反映されるので、**タップと同じフレームで吹き出しが出る**

グループは**バックエンドと権限ルールは対応済みだが、作成 UI がまだ無い**。

### 4〜6. スタンプ

- 正本は1つ。メッセージは `StickerId` だけを運ぶ
- 受信側は初回だけ取得 → SHA-256 で照合 → `filesDir` に保存 → 以後ネットワーク不要
- 同じスタンプが20個並んでも**ダウンロードは1回**

**Cloud Storage は使っていない。** 200KB 上限のスタンプは Firestore の 1MB 制限に収まり、
Cloud Storage が解決する問題（ドキュメントに入らない大きさ）が起きない。Blaze プランも不要。
移す必要が出たら `StickerRepository` の中身だけが入れ替わる。詳細は ROADMAP。

### 7. 再インストール・ログイン後の復元

会話・設定・スタンプの所有情報はアカウントから戻る。画像は必要になった時だけ取りに行く。
**スタンプを100個持っていてもログイン直後に100個は落とさない。**

`allowBackup="false"`。Android のクラウドバックアップには何も預けない。

### 8. Analytics

`FirebaseAnalyticsSink` を接続。広告ID収集と自動画面レポートは manifest で停止。

**プライバシー画面**を追加（アカウント → プライバシーと計測）。何を送っていて何を送っていないかを
並べ、送信を止めるスイッチを置いた。

### 9. フィードバック

投稿・一覧・投票・取り下げ。他の人の要望も見えて、票を足せる。

> フィードバックの本文は Firestore に保存され、開発者が読む。
> これはメッセージ本文とは**別の話**で、書いた本人が開発者宛てに書いたものだから。
> Analytics に行くのは**長さだけ**。

## 検証したこと

### セキュリティルール（26件、エミュレータで実行）

```bash
cd rules-tests && npm install && npm test
```

ROADMAP が必須としていた確認を、主張ではなく実行できる形にした。

- 参加者は本文を読める / **参加者以外は読めない** / 未ログインは読めない
- **`admin: true` `staff: true` を名乗るトークンでも読めない** — 管理者用の抜け道がルールに無い
- 送信後に本文を書き換えられない
- 他人になりすまして送れない・他人のリアクションを書けない・他人の既読を書けない
- 利用者一覧も招待コード一覧も列挙できない
- 会話は削除できない（片方が消すと相手の履歴も消えるため。抜けるのはメンバーからの離脱）

### 実機（Pixel 10）

- 起動・プロフィール作成・招待コード発行まで確認
- 空の会話一覧が正しく出る

### まだ確認していないこと

**人対人の送受信を実機で通していない。** 2つ目のアカウントが要る。
Echo を入れた端末がもう1台あるか、別のアカウントでログインすれば試せる。
