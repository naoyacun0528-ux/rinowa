# Echo 0.1.1

2026-08-15 / Prototype 0 / Android only

Prototype 0 の合格条件6項目は 0.1.0 の時点で開発者本人が実機判定し、**すべて合格**。
0.1.1 はその後の指摘を反映した版です。

---

## 触ってわかる変更

### リアクションを押し直せるようになった（新機能）

メッセージに付いているリアクションを**タップするとピッカーが開きます。**

これまでリアクションを変える手段は「もう一度バブルを長押しする」だけでした。
すでにリアクションが見えている状態では、それを押すのが自然な動作であり、
押しても何も起きないのは壊れているように見えます。

タップで開いた場合は最初から**タップ選択モード**で開きます（指を滑らせる余地がないため）。

### リアクションは1人1つになった

2つ目を選ぶと1つ目が取り消され、差し替わります。同じものをもう一度選べば取り消しです。

「1つ」は**自分の分が1つ**という意味です。他の人が付けたリアクションはそのまま残り、
自分の1票だけが抜けます。

### 触覚を全体的に高くした

「全体的に低く重い」という指摘を反映しました。

周波数を上げる方法は階層によって違います。

- **Envelope 階層**（reaction / success / warning / error / destructive）
  → `sharpness` が周波数そのもの。全トークンで引き上げ
- **プリミティブ階層**（selection / navigation / softConfirm / send / threshold / thresholdRelease）
  → 周波数は OS が固定しているため指定できない。より高い形へ差し替え
  （`TICK` > `CLICK` > `LOW_TICK` / `THUD` の順に高い）

トークン間の順序関係は保っています。`error` と `destructive` は**意図的に低いまま**なので、
他が上がったぶん以前より際立ちます。

`threshold` だけ `CLICK` のまま残しました。唯一「硬く確定した」と感じるべき瞬間であり、
同じ画面で隣り合う `send` と区別がつく必要があるためです。

## 直した不具合

### 返信スワイプがバブルを二重に描き、触覚が2回鳴っていた

原因は1つでした。ジェスチャの検出を、**そのジェスチャ自身が動かしている要素**に付けていたためです。
指の座標はその要素基準で報告されるので、バブルが動いた分が次の読み取りから差し引かれ、

```
offset = 指の移動量 − offset   →   offset = 指の移動量 ÷ 2
```

に収束しつつ、毎フレーム振動していました。振動が二重描画に見え、
閾値をまたぐたびに触覚が鳴っていました。

実測での確認（410px を 1200ms、閾値 189px）:

| | 閾値到達 |
|---|---|
| 修正前 | 1089 ms |
| 修正後 | **549 ms**（幾何からの理論値 553 ms） |

### 長押しして指を離しただけでリアクションが確定していた

ピッカーはバブルの真上に出るため、開いた指は必ずどれかの絵文字の真下にいます。
指は必ず微動するので、その瞬間に選択が入っていました。

判定を「近さ」から**「動かしたかどうか」**に変更。長押し位置から 18dp 動くまで
スライド選択に入りません。静止したまま離せば必ずピッカーが残り、
動かせばスライド選択になります。両者が排他になりました。

### スワイプ位置が全メッセージで共有されていた

あるバブルの戻りアニメーション中に別のバブルをスワイプすると、
1つの値を2つの処理が奪い合い、途中で勝手に戻っていました。行ごとに独立させました。

### その他

- 閾値にヒステリシスを追加（境界に指が乗っているだけで触覚が振動しないように）
- スレッドの整形計算が**コンポーザーに1文字打つたびに全メッセージを複製・比較**していたのを修正

## まだ対応していない

- **触覚の再判定**が必要です。今回の高域化が正しい方向かは実機で触らないと分かりません
- 未決の論点: `send` と `threshold` をプリミティブのまま置くか、Envelope へ移すか。
  Envelope なら周波数を直接指定できますが、**最短 40ms** になります
  （Pixel のコントロールポイント最小長が 20ms のため）。
  Haptic Lab の「Tier を固定して比較」で T4 と T3 を切り替えれば、その場で判断できます
- Canvas で描いたアイコンに読み上げ用の説明がありません（TalkBack 未対応）

## 入れ方

USB デバッグを有効にした端末を繋いで、

```bash
adb install -r echo-0.1.1-debug.apk
```

すでに入っている場合も `-r` で上書きされます。データは保持されます。

このアプリは `jp.echo.android.debug` として入ります。
NEON INSTINCT など他のアプリとは別物なので、共存します。
