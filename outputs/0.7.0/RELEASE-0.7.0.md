## プロフィール編集

**アカウント → プロフィールを編集**

- **名前**（40字まで）
- **ひとこと**（120字まで・任意）
- **写真**

写真は会話一覧の相手のアイコンにも出ます。設定しても他で見えないなら意味がないので。

### 元の写真は端末から出ません

スタンプで決めたのと同じ原則です。カメラで撮った写真は数MBあり、**EXIF に撮影場所が
入っていることがよくあります**。40dpの丸を描くためにそれを送るのは、位置情報の履歴を
アバターのために送ることになります。

端末内で **正方形に切り抜き → 256px に縮小 → 再エンコード** してから保存します。
**再エンコードがメタデータを落とします** — 送られるバイト列はこの処理が作ったもので、
選んだファイルのコピーではありません。

画面にもその旨を書いてあります。安心してよい部分であり、かつ事実なので。

### 権限を要求しません

Android の**フォトピッカー**を使っています。選んだ1枚だけが渡され、**写真ライブラリへの
アクセス権はアプリに与えられません**。アバターを設定するためにストレージ権限を求めるのは、
1つ借りるために家の鍵を渡すようなものです。

### ハッシュでキャッシュ

画像は内容のハッシュで保存し、ユーザードキュメントには同じハッシュだけを持たせます。
**手元のコピーが最新かどうかを、画像を落とさずに判定**できます。変更するとハッシュが
変わり、そのとき1回だけ再取得されます。

画像は本体ドキュメントとは別に置いています。`users/{uid}` は名前を引くたびに読まれるので、
そこに数十KBの画像を混ぜると、**一覧を開くだけで人数分の画像を落とす**ことになります。

## セキュリティルール

プロフィール画像は署名済みなら誰でも読めます。本文とは性質が違い、**本人が「見せるために」
置くもの**だからです。招待コードで会話を始めた相手にも見える必要があります。

書き込みは本人のみ、サイズ上限つき。テストは 29 件すべて通過しています。
