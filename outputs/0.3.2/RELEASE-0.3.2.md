# Echo 0.3.2

2026-08-15 / Prototype 0 / Android only

**送信ボタンに八角形が見えていた不具合の修正。**

---

## 何が起きていたか

ライトモードで送信ボタンの中に、淡い八角形が浮かんで見えていました。

原因は **Android の影の描き方**です。

Android は影を、輪郭をなぞった**多角形にテッセレーション（分割）した図形**として描きます。
通常は影の上に不透明な塗りが乗るので見えません。

ところが送信ボタンの塗りはグラデーションの下端が 86% 不透明、
つまり**わずかに透けていました。** その結果、

> **自分の影の多角形が、自分の塗りを透けて見えていた**

という状態になっていました。八角形は影の分割形状そのものです。

隣の `+` / スタンプボタンに出ていなかったのは、そちらの塗りが不透明だったためです。

## 切り分け方

推測で直さず、順に潰しました。

1. 拡大して形を確認 → 中央に八角形、外周は暗い
2. **文字を入力して有効状態にする** → 塗りが濃くなっても八角形は残る
   → 「無効時の半透明」だけの問題ではない
3. 隣の不透明なガラスボタンには出ていない → **透明度が関係している**
4. 透明度をやめて不透明色に変更 → **消えた**

## 修正

透明度で薄くするのをやめ、**背景色に混ぜた不透明色**にしました。

```
❌  accent.copy(alpha = 0.35f)          背後の影が透ける
✅  lerp(background, accent, 0.35f)     見た目は同じ、透けるものが無い
```

見た目は変わらず、背後に透けるものが無くなります。

---

## 同じ問題が起きうる場所

**影と半透明を重ねない**、という原則として記録しました（`CLAUDE.md`）。

ガラス UI は影と透明感を近くで使う設計なので、これは今後も繰り返し起きうる種類の問題です。
薄くしたいときは alpha ではなく背景色との混合を使います。
