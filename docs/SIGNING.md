# 署名鍵（keystore）

Android アプリは署名鍵で「同じアプリである」ことを証明します。
**鍵が変わると、Android は別のアプリとして扱います。**

---

## 最初に読むこと

> ## この鍵を失うと、二度と取り戻せません。
>
> 鍵ファイルを失った場合、またはパスワードを忘れた場合、
> **すでに配ったアプリへアップデートを届ける手段が永久に失われます。**
>
> 復旧手段はありません。Google にもアップルにも私にも、再発行はできません。
> できるのは「別のアプリとして作り直し、全員に古いほうを消してもらう」ことだけです。
> その時点でトーク履歴も設定もすべて消えます。

これは大げさな話ではなく、Android の署名の仕組みそのものです。

---

## 置き場所

| もの | 場所 |
|---|---|
| 鍵ファイル | `C:\dev\echo-keys\echo-release.jks` |
| パスワード | `C:\dev\echo\android\keystore.properties` の中 |

**鍵はリポジトリの外に置いています。** 中に入れると、いつか誤ってコミットされる日が来るためです。
`keystore.properties` は gitignore 済みで、git の履歴にも入っていません。

パスワードは生成時にランダムで作ったもので、**会話には出していません。**
`keystore.properties` を開けば書いてあります。

---

## バックアップ（あなたにしかできない作業）

作業環境はセッションをまたいで秘密を保持しません。
**鍵の保管者はあなたです。** 以下を今のうちにやってください。

コピーするものは2つです。

```
C:\dev\echo-keys\echo-release.jks
C:\dev\echo\android\keystore.properties
```

置き場所は **PC 以外を最低1つ** 含めてください。この PC が壊れたら終わり、という状態を避けるためです。

- USB メモリや外付けドライブ
- 自分だけがアクセスできるクラウドストレージ
- 保護者に預ける（配布の段階では結局この話になります）

**やってはいけないこと**

- 公開リポジトリや共有フォルダへ置く
- 他人に見える場所へパスワードを書く
- 鍵とパスワードを同じ USB だけに入れて、そのUSBを紛失する

## この鍵の指紋

APK がこの鍵で署名されているかを確認するための値です。**秘密ではありません。**

```
SHA-256  53:15:50:1D:D0:83:20:A3:5E:A8:41:B4:EE:48:B7:C5:CB:56:27:E1:BF:FA:67:D4:49:35:91:AD:C4:38:5F:F9
SHA-1    8E:7B:1B:D2:BA:AF:B9:73:82:CF:8A:1D:A5:D6:36:89:05:3C:56:E7
```

確認方法:

```bash
apksigner verify --print-certs --min-sdk-version 24 echo-0.1.2-release.apk
```

作成時の設定: RSA 4096bit / SHA384withRSA / 有効期間 10000日（約27年）/ alias `echo`

## ビルドでの扱い

`android/app/build.gradle.kts` が `keystore.properties` を読んで release ビルドに署名します。

**このファイルが無い環境では、release ビルドは署名なしになるだけで失敗しません。**
配布しているソース zip には含まれないため、他の人がビルドしても止まらないようにしてあります。

debug ビルドは従来どおり開発用の鍵で署名され、`blog.nextlab.echo.debug` として入ります。
release とは applicationId が違うので、同じ端末に両方入れられます。

---

## 将来 Google Play へ出す場合

Play には **Play App Signing** という仕組みがあります。
Google が本物の署名鍵を預かり、開発者は「アップロード鍵」だけを持ちます。

- アップロード鍵を失っても、Google に再発行を依頼できます
- **鍵の紛失で詰む、という最大のリスクが消えます**

配布を現実に検討する段階では、これを使う前提で考えてください。
その場合、いまの `echo-release.jks` はアップロード鍵として使えます。

なお [ROADMAP.md](ROADMAP.md) のとおり、ストア公開は開発者本人が13歳であるため
保護者の正式な関与が前提になります。**名義だけを借りる形では進めません。**
