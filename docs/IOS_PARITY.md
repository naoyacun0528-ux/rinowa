# iOS はどこまで Android に追いついたか

2026-08-29 時点。数えた結果であって、見た印象ではない。

## 画面 — 揃った

Android の画面 17、iOS 15。差の2つは `DirectLabScreen` と `HapticLabScreen` で、
**どちらも実験用**。移す対象ではない。

つまり **製品の画面は全部ある。**

| | |
|---|---|
| 一覧・会話・写真・通話・安全・プロフィール・プライバシー・バックアップ・サインイン | 前からある |
| 友達を追加・グループを作る | 今日足した |
| アカウント・メール確認・パスワード再設定・アカウント削除・フィードバック | 今日足した |
| プロフィール写真の切り抜き | 今日足した |

## 見た目 — 揃えた

一度ずれていた。**移植ではなく書き直しになっていて、iOS 単体では自然な選択を
していた。** 二台並べると別のアプリに見えた。

| | 直す前 | 直した後 |
|---|---|---|
| ＋の色 | 白 | accent（オレンジ） |
| ＋の形 | SF Symbols | Canvas で引いた線（太さ2.4、端は丸、0.22〜0.78） |
| ＋の背景 | Apple 既定の `.regularMaterial` | 独自の `GlassSurface` |
| ＋のメニュー | 横から滑る | 上へ伸びる |
| 一覧の行 | 区切り線で仕切った並び | 浮いたガラスのカード |
| スタンプ | 絵文字を文字として表示 | Android と同じ画像8枚 |
| 写真 | 1枚だけ | 横にめくれる |

`RinowaGlass.kt` → `Glass.swift`、`AuthComponents.kt` → `Controls.swift`。
**値は1つも変えていない。** 角丸22、カード余白12、間隔7、影の段（5 / 3）、
押したときの膨らみ（1.018 / 1.075）まで同じ。

## 言葉 — まだ揃っていない

`tools/check-strings.mjs` で数えられる。iOS に出てくる日本語が Android に
同じ形で存在するかを見る道具で、**写さずに書き直したときだけ破れる。**

今日足した画面の文言は全部写したが、**前からある画面には書き直したものが残っている。**
どちらへ寄せるか（Android の長い説明を iOS に合わせて削るか、逆か）が
決まっていないので、CI には入れていない。

## 中身 — ここが本丸

**画面はあるが、繋がっていない。**

| | Android | iOS |
|---|---|---|
| メッセージの送受信 | Firebase Firestore | **無い**（見本データ） |
| ログイン | Firebase Auth | **無い**（画面だけ） |
| 封をする | Matrix Olm/Megolm | **無い** |
| 通話 | WebRTC | **無い**（状態の遷移だけ） |
| 通知 | FCM | **無い** |
| バックアップ | Google Drive | **無い**（画面だけ） |

招待コードを入れても「見つかりませんでした」しか返らない。グループを作っても
作られない。**手順と見た目は同じで、その先が空いている。**

ここを埋めるのは画面を写す作業ではなく、SDK をひとつずつ入れて、鍵の扱いを
両方で一致させる作業になる。**実機が無いと確かめられない部分**でもある。
