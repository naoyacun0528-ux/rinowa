# 名前

**この文書が正本。** どこかの文書と食い違ったら、こちらが正しい。

## どこで、どの名前を使うか

**「内と外」で分けない。「使っているとき」と「見せているとき」で分ける。**

| 場所 | 使う名前 | 例 |
| --- | --- | --- |
| アプリの画面・設定・問い合わせ | **普通の言葉** | 「このメッセージは暗号化されています」 |
| **製品紹介・仕様ページ・人に見せるとき** | **コード名が主役** | 大きく **Yosegi**、小さく Rinowa Original Format |
| 設計文書・コード | 正式名称＋コード名 | `# Rinowa Original Format — Yosegi v1` |

**使っている人はコード名を知らなくていい。見せる相手には、コード名しか刺さらない。**

紹介ページ（`site/yosegi/`）が成立しているのは、表紙に大きく **Yosegi** と出ているからで、
そこに「RINOWA ORIGINAL FORMAT」と書いてあったら誰も読まない。

そしてコード名が紹介で効く理由は、**選定条件そのもの**にある。

> 読めるが、**意味はすぐ分からない**。

「Yosegi って何？」と思わせた時点で、**そこから説明が始まる**。
意味が分かる名前は説明が要らないので、会話が始まらない。
役割名（Original Format）は説明そのものなので、**問いを作れない**。

| 表に出す名前 | コード名 | 読み | 中身 |
| --- | --- | --- | --- |
| **Rinowa Original Format** | **Yosegi v1** | ヨセギ | ワイヤ形式。圧縮せずに封筒を削る |
| **Rinowa Security System** | **Sigil v1** | シジル | 封の仕組み。本文・写真・動画・通話・バックアップ |
| **Rinowa Direct Network** | **Yosuga v1** | ヨスガ | サーバーを通さず端末同士で届ける経路 |
| **Rinowa Haptic Design** | **Nagori v1** | ナゴリ | 触覚 |
| **Rinowa Interface Experience** | **Utsuroi v1** | ウツロイ | 画面・配色・動き |
| **Rinowa Network Core** | **Shirube v1** | シルベ | 端末を経由して運ぶ仕組み（研究段階） |
| Rinowa Cloud International | — | | 通常のサーバー経由の経路 |
| Rinowa Account Secure | — | | 身元まわり |

**コード名が付くのは、発明と呼べるものだけ。**
Cloud と Account は仕組みであって作品ではないので、役割名で足りる。

## 名前の付け方

```
Rinowa  <役割 2語>  [ - <コード名> v<n> ]
```

- **単独で立たせない。** 必ず `Rinowa` を冠する
- **役割は英語2語。** 1語だと軽く、3語だと重い
- **略さない。** 略号は名前から力を抜く
- **語順は正しい英語に寄せなくていい。** `Account Secure` は `Secure Account` にしない
- **コード名は互いに似せない。** 別々の発明なので、揃っているほうがおかしい

### コード名の条件

**日本語話者が聞いて、読めるが意味はすぐ分からないこと。**

意味がすぐ分かる語は、その語が元々持っている絵を連れてくる。
「気配」と言われたら日常の気配が浮かんでしまい、**名前が自分のものにならない**。

| | 読める | 意味がすぐ分かる | |
| --- | --- | --- | --- |
| Rinowa | ○ | ✕ | 造語。何も連れてこない |
| Sigil | △ | ✕ | 英語だが日常語ではない |
| Yosuga（縁） | ○ | ✕ | 縁を「よすが」と読む人は少ない |
| Kehai（気配） | ○ | **○** | 落選 |
| Vitrum | **✕** | ✕ | 落選。読めない名前は使われない |

**人名になる語は使わない。** Shiori（栞）、Fumi（文）、Nagi（凪）、Kiriko（切子）は
どれも実在の人名なので落選した。

## コード名の由来

| | |
| --- | --- |
| **Yosegi**（寄木） | 留め具を使わず、部品の形と順序だけで組み上がる工芸。区切り文字も名札も詰め物も入れない形式そのもの |
| **Sigil** | 封印の紋章。**1つ1つに刻むもの**。メッセージ1通ごとに封をするので、盾や結界ではなくこの語を選んだ |
| **Yosuga**（縁） | 頼りにして辿り着くための手がかり。足場を持たない Direct が相手に届くために掴むもの |
| **Nagori**（名残） | 過ぎたあとに残る気配。振動が終わったあとに手に残っているもの |
| **Utsuroi**（移ろい） | 光と色が時とともに変わること。動きと配色を1語で言える |
| **Shirube**（標） | 道を示す目印。どの端末を経由すれば届くかを探す仕組みに合う |

## 文書の在り処

| コード名 | 文書 |
| --- | --- |
| Yosegi | `YOSEGI_V1_SPEC.md`（凍結） |
| Sigil | `RINOWA_SIGIL.md`（適用範囲の正本） |
| Yosuga | `DIRECT_ARCHITECTURE.md` ／ `DIRECT_THREAT_MODEL.md` |
| Nagori | `HAPTIC_DESIGN.md` |
| Utsuroi | **まだ無い。** 実装は `android/core/designsystem/` |
| Shirube | `RESEARCH_MESH.md`（研究のみ・実装しない） |

## 動かせない名前

改名のたびに引っかかるので書いておく。**この2つは名前を揃えてはいけない。**

| | なぜ |
| --- | --- |
| `BackupCipher` の `"LOWANBK"` | 既に Drive にある書庫の先頭バイト。揃えると過去の書庫が全部読めなくなる |
| `CryptoIds.DOMAIN = "lowan.local"` | 全端末の識別子と部屋 id に焼き付いていて、公開済みの鍵にも入っている |

`outputs/` 以下の過去のリリースノートも書き換えない。
出荷した時点の名前がそれであって、後から直したら記録ではなくなる。
