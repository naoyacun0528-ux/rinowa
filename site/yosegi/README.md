# Yosegi 紹介ページ — ソース

`https://echo.nextlab.blog/yosegi/` の中身。

Rinowa（アプリ）のワイヤ形式である **Yosegi v1** を紹介する1枚のページ。
数字はすべて `docs/YOSEGI_V1_SPEC.md` と `docs/RESEARCH_WIRE_FORMAT.md` の実測から取っている。

## ファイル

| | |
| --- | --- |
| `core.html` | **本体。** CSS・本文・スクリプトが全部ここに入っている |
| `build.mjs` | `core.html` を包んで `index.html` を作る。head と OGP の指定はここ |
| `og.html` | OGP画像を焼く。ブラウザで開いて「保存」 |
| `og-6.jpg` | 焼いたもの（1200×630、約 50KB） |
| `serve.mjs` | 手元で見るための小さなサーバー |
| `htaccess` | 配備先では `.htaccess` として置く。キャッシュの指示だけ |
| `moved.html` | 旧アドレス `/rinowa/` に置いてある転送ページ |

## 作る

```
node build.mjs      # index.html ができる
node serve.mjs      # http://localhost:4319 で見る
```

## 配る

`index.html` と `og-6.jpg` と `htaccess`（`.htaccess` として）を
`echo.nextlab.blog/yosegi/` に置くだけ。

**画像を差し替えたら名前も変えること。** `og-6.jpg` → `og-7.jpg`。
同じ名前のままだと、一度読んだ端末も LINE も古いほうを出し続ける。
`build.mjs` の中の名前も合わせて変える。

## 作りの前提 — ここを崩すと壊れる

### 1. CSS に「動き」を書かない

配備先のサーバーはページの CSS を勝手に組み替え、
**読み込んだ瞬間に効いていない規則を落とす。**

`opacity:0` から始める動きはまさにそれに当たり、
一度これで**表題と大きな数字が出なくなった**（戻す側の規則だけが消えた）。

だから:

- `<style>` には**完成した姿だけ**を書く。隠す規則は1つも書かない
- 隠れている初期状態は、各要素の **`style` 属性に直接**書く（属性は組み替えの対象外）
- 動きは **Web Animations**（`element.animate`）で回す

こうすると、規則を落とされても・スクリプトが遅れても、
**壊れ方が「動かないだけで全部見える」に収まる。**

`.htaccess` からこのサーバー機能は止められない（指令が許可されておらず 500 になる）。
`?PageSpeed=off` を付けると素のまま返ってくるので、切り分けにはこれを使う。

### 2. 出現の順序に頼らない

安全網（`__rinowaBail`）は「本体が1行も走らなかったとき、隠したまま人に見せない」ための保険。
本体が `clearTimeout` するだけの作りにしていたら、**実行順が逆になって解除が効かず**、
保険が先に隠しを外し、そのあと `play()` がもう一度隠してから出し直していた。
「出てから、消えて、また出る」という見え方になる。

いまは順序に頼らない:

- 本体は最初の1行で `window.__rinowaLive = true` を立てる
- 保険はそれを見て、立っていれば何もせず引き下がる
- `play()` は**すでに見えている要素には一切触らない**

さらに各アニメーションには見張りが付いていて、予定時刻を過ぎたら取り消して
完成した姿に戻す。時計が進まない環境（描画されないタブなど）でも隠れたままにならない。

### 3. `background-clip: text` の箱は文字より小さい

グラデーションの背景は**要素の箱のぶんしか存在しない**。
`line-height:1` だと箱の下端がほぼ基準線なので、**g の尾に色が乗らない**。

`.wordmark` では下に余白を足して背景の箱を伸ばし、
**同じ量の負のマージンで配置は動かしていない**。

同じことが OGP画像でも起きる（`og.html` の `TOP`/`BOT` を参照）。
グラデーションは固定範囲ではなく**字面の実寸**に張ること。

### 4. 日本語は語の途中で折らない

`.jp` に `word-break: keep-all` を掛け、折れてよい場所を `<span class="u">` で区切ってある。
行そのものを分けたいところは `<span class="ln">` を入れる。
`.ln` は `overflow:hidden` で、中の `.li` が下からせり上がる幕になっている。

### 5. 1枚の面が1画面

`.stage` に `min-height:100svh` と上下中央揃え。
短い面でも次の面が下から覗かない。内容の多い面（4機種）だけ自然に伸びる。

## 色と書体

| | |
| --- | --- |
| 地 | `#07080C`（青に寄せた黒）／ 段差 `#11151D` |
| 文字 | `#F7F9FB` ／ 本文 `#C9D2DC` ／ 補助 `#A9B4C0` |
| 差し色 | `#B4D4F7` |
| 数字と欧文 | Archivo 800 |
| 見出し | Zen Kaku Gothic New 900 |
| 本文 | Noto Sans JP 500 |

小さい文字ほど背景に沈むので、**実測で全要素 8.6:1 以上**に取ってある（基準は 4.5:1）。
色を暗くするときはここを下回らせないこと。

暗い1色に決め打ちしている。閲覧側の明暗設定は見ない。
